# TPSMod

## Branches
The `dev` and `main` branches contain source code for the current revision (3.x.x)

The `legacy` branch contain source code for old versions (0.x.x, 1.x.x, 2.x.x) either as-is or reconstructed along with binaries.
These versions can be reconstructed using the standard MinecraftForge MDK for 1.7.10 for 0.x.x and 1.x.x. 2.x.x can be compiled from the
[LitLaunch Source Code Repository](https://github.com/Codetoil/LitLaunch-Minecraft)

## Installing

If you need help with any of these, join my Discord. Links can be found at the bottom of the README.

### TPS Mod - How to install - 3.x.x
This mod supports a variety of platforms though which ones depend on the version. Installing this mod should be the same as how one usually download mods.

### TPS Mod - How to install - 2.x.x
This mod is for [LitLaunch](https://www.curseforge.com/minecraft/mc-mods/litlaunch) for Minecraft 1.7.10, 1.8.9, 1.12.2, 1.14.4 and 1.15.2 (though it is broken on 1.14.4 and 1.15.2)
Put the tpsmod jar into a new folder named, "mods_litlaunch", within the .minecraft folder

### TPS Mod - How to install - 0.x.x/1.x.x
This mod is for Minecraft Forge for Minecraft 1.7.10. Installing this mod should be the same as how one usually download mods.

# Building
Simply clone the repository via git and import all gradle repositories.

# Pull request format and acceptability

Once reviewed, the pull request might be accepted or declined based on whether the code is with the rules of the mod.

### The rules of the mod (for pull requests)

-Don't change the code to:

-harm someone

-harm a group of people

-harm the public

-Don't change the code to give yourself an advantage over someone else in any way. I'm not making this mod a hacked client!

-All changes in the code must not change anything gameplaywise. Again, I'm not making this mod a hacked client!

#### This is not an inclusive list and I may have rules not written down here.

### Free speech - But keep on topic.
In the discussion pages, you may speak whatever you want, as long as it complies to the topic. This allows for naughty language in the discussion pages. People who are off topic may be punished though, so stay on topic!
The free speach statement can be overriden by Github's own rules if it has any against free speech, though off-topic-ness is still punished.
